# 🎯 LinkedIn Job Tracker - Your AI-Powered Job Search Assistant

## What We Built
An intelligent job application tracker that automatically syncs with Gmail, uses AI to score job matches based on your actual resume, and provides real-time insights about your job search journey.

## The Problem We Solved

### Before This System:
- Tracking 50+ applications in spreadsheets was a nightmare
- No idea which companies viewed your application
- Couldn't remember what position you applied for where
- No insights into which jobs were actually a good fit
- Manually updating status for each application
- Lost in a sea of LinkedIn emails

### After This System:
- All applications automatically imported from Gmail
- AI scores each job match (0-100%) based on YOUR resume
- Real-time status tracking (Applied → Viewed → Interview)
- Smart insights showing response rates and timing patterns
- One-click sync keeps everything current
- Never miss a follow-up opportunity

## How It Works (In Plain English)

### 1. **Connect Your Gmail**
   - Secure OAuth connection (no passwords stored)
   - Automatically finds all LinkedIn job emails
   - Imports application history from the last 90 days
   - Updates in real-time as new emails arrive

### 2. **AI Analyzes Everything**
   - GPT-4 reads each email and extracts job details
   - Compares job requirements to your actual resume
   - Calculates match scores for skills, experience, location
   - Provides specific suggestions for each application

### 3. **Track & Optimize**
   - See which companies viewed your application
   - Track average response times
   - Filter by status, location, or job type
   - Export data for deeper analysis
